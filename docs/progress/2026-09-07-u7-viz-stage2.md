## What changed (apps/game)

All geometry comes out of `tools/hero_props.py` (Blender 4.5.5 headless → `assets/models/hero/*.glb`); the script
now takes optional prop names so one prop can be regenerated alone. Materials in the .glb stay palette *names* that
`scripts/props.gd` maps onto the WingTheme; two names were added — **SteelDark** and **BrassDark** — derived from the
theme's steel / brass (no new theme exports, no textures, no atlas: flat colour + bevels was enough).
