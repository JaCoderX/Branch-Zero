## Asset decision — Quaternius is no longer CC0

The kickoff preferred Quaternius. Every Quaternius pack page still shows a **CC0** badge, but the site's licence page is
now the **Quaternius Asset License (QAL) v1.0, dated 2026-08-28**: free for personal, educational and commercial *products*,
no attribution, but §3(a) forbids redistributing the assets "in original or modified form" as standalone files, and only
"a completed Product that merely incorporates the Assets" is exempt. Raw `.glb` files committed to this public MIT repo
sit on the wrong side of that line, and the downloads are Google Drive folders (no direct file), which the kickoff also
named as the fallback trigger. So the kickoff's other option was taken — **an equally licensed (CC0) adult-ish low-poly
kit with the four clips**: Kenney **Blocky Characters 2.0** (direct zip, its `License.txt` says CC0 1.0). If the principal
ever wants Quaternius, that is a licence call, not a technical one; the fetch route would be `gdown --folder`.

Kenney Mini Characters 1.0 (Stage 1) is retired from the repo — the files are in git history before this commit.
