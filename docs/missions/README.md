# Missions — handoffs & kickoffs

Agent briefings for Branch Zero construction units. Product docs stay in `docs/`; these files are the paste-ready mission packets.

| Prefix | Role |
|--------|------|
| `HANDOFF-*.md` | Outcome / status brief for the next agent or human |
| `KICKOFF-*.md` | Mission block to paste into a new agent session |
| `HANDOFF-CC.md` | Cold-start index — current freeze, open lanes, next mission |

Index of active / recent briefs: [`../README.md`](../README.md). Checklist: [`../OWED.md`](../OWED.md).
